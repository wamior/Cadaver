# Cadaver

**После смерти ваше тело остаётся там, где вы погибли, и хранит всё, что было при вас.** Вернитесь, откройте труп и заберите вещи.

Cadaver — лёгкий мод на трупы. Труп не мешает в бою, таймер исчезновения действительно работает, а предметы из других модов попадают туда, куда нужно.

---

## ✨ Возможности

### 🧍 Настоящее тело
Труп — это ваша модель игрока со скином, лежащая на спине. Скины работают и на серверах без лицензии с SkinsRestorer.

### 🎒 Только то, что должно было выпасть
Cadaver собирает **итоговый** набор выпавших предметов, поэтому всё, что решили другие механики, сохраняется:
- предметы с **проклятием утраты** исчезают, как в ванилле;
- при **`keepInventory`** труп не появляется, вещи остаются у вас;
- **«привязанные» зачарования** из других модов оставляют свои предметы у игрока;
- учитываются правила выпадения **Curios**.

### 🔫 Нет хитбокса в бою
Пули (**TaCZ** и другие оружейные моды), стрелы, удары и прицел проходят сквозь трупы. Гора тел не съедает выстрелы и не закрывает игрока за ней.

### 🗂️ Понятное окно трупа
У каждой части инвентаря своя секция:
- **броня** — с иконками пустых слотов;
- **левая рука**;
- **инвентарь** и **хотбар** — в исходном порядке;
- **аксессуары Curios** и **прочие модовые предметы** — на боковой панели.

Предметы можно только забирать: использовать труп как бесплатный сундук не получится.

### ⚡ Быстрый лут
**Shift + ПКМ** забирает всё разом. Владелец получает каждый предмет **в его прежний слот**: броня надевается обратно, хотбар восстанавливается, аксессуары возвращаются в слоты Curios.

### ⏳ Таймер, который работает
Время отсчитывается с момента смерти, **даже пока чанк выгружен**: просроченный труп исчезает, как только его чанк загрузится. Предметы при этом либо выпадают на землю, либо удаляются — как выставлено в конфиге.

### 🛡️ Дополнительно
- **Защита владельца** (по желанию): первые N минут открыть труп могут только владелец и операторы
- **Координаты смерти** в чате
- **Уведомление о новой версии** в чате (можно отключить)
- Трупу не страшны огонь, лава, взрывы и урон, и он никогда не проваливается в пустоту

## ⚙️ Настройки

Файл: `config/cadaver-common.toml`. Изменения применяются **без перезапуска**.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `general.enabled` | `true` | Создавать трупы при смерти |
| `general.sendCoordinates` | `true` | Писать координаты трупа в чат |
| `general.updateNotice` | `true` | Уведомлять в чате о новых версиях |
| `general.dimensionBlacklist` | `[]` | Измерения без трупов (там предметы выпадают как в ванилле) |
| `despawn.despawnMinutes` | `60` | Через сколько минут труп исчезает, `0` — никогда |
| `despawn.dropItemsOnDespawn` | `true` | `true` — при исчезновении предметы выпадают, `false` — удаляются |
| `despawn.removeWhenEmpty` | `true` | Убирать опустевший труп |
| `access.ownerProtectionMinutes` | `0` | Сколько минут лутать может только владелец, `0` — выключено |
| `access.quickLoot` | `true` | Разрешить Shift + ПКМ, чтобы забрать всё |

## 🔌 Совместимость

- Нужен **и на клиенте, и на сервере**
- **Curios API** — необязательно, поддерживается полностью
- **TaCZ** и другие оружейные моды — трупы не блокируют выстрелы
- Работает вместе с модами, которые сохраняют вещи после смерти: Cadaver забирает только то, что должно было выпасть

## 📦 Сборки

Cadaver можно добавлять в любые сборки на CurseForge и Modrinth, спрашивать не нужно.
